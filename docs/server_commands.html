Stack se skládá ze 4 procesů běžících pod PM2 (definováno v server-scripts/ecosystem.config.js) + samotného herního serveru řízeného skriptem telnet_restart_7d2d.sh.

  2. Monitoring stavu: pm2 list, pm2 logs, tail -f na jednotlivé logy
  3. Hráčský zážitek: hráč hlasuje / hraje → voting-rewards / game-monitor zaznamenají událost → quest cronjoby v Takaro aktualizují progres → autoClaimRewards.js / autoClaimPendingRewards.js automaticky vyplatí odměnu
  4. Automatické restarty: cron volá telnet_restart_7d2d.sh restart (5min countdown), PM2 procesy běží nezávisle a přežívají restart herního serveru
  5. Údržba: telnet pro admin příkazy, PM2 + soubory v Logs/ pro troubleshooting

🚀 Server Control Commands

⭐ Kompletní start / stop / restart celého stacku

~/7D2DBohemia/server-scripts/lifecycle/full_stack_start.sh# Start 7D2D server + počká 45s + spustí všechny PM2 procesy + uloží PM2 startup
pm2 stop ecosystem.config.js# Zastaví všechny PM2 procesy (server-scripts adresář)
~/7D2DBohemia/server-scripts/lifecycle/telnet_restart_7d2d.sh stop# Zastaví jen herní server (graceful shutdown přes telnet)
~/7D2DBohemia/server-scripts/lifecycle/telnet_restart_7d2d.sh restart# Restart herního serveru s 5min countdownem pro hráče
pkill -f 7DaysToDieServer# Nouzové okamžité zabití herního serveru

Manuální / nouzový start herního serveru

cd ~/7d2d-server# Přejít do adresáře serveru
./7DaysToDieServer.x86_64 -configfile=serverconfig.xml -quit -batchmode -nographics -dedicated# Ruční start bez wrapperu (bez logování do restart.log)

Správa PM2 procesů (Quest server / Monitor / Voting)

pm2 list# Přehled všech běžících procesů, uptime, mem, cpu
pm2 start ecosystem.config.js# Spustit všechny procesy definované v ecosystem.config.js
pm2 restart game-monitor# Restart konkrétního procesu (podle jména z pm2 list)
pm2 restart takaro-server# Restart Node.js quest integračního serveru
pm2 restart voting-rewards# Restart voting scriptu
pm2 stop <name># Zastavit konkrétní proces
pm2 delete <name># Odstranit proces z PM2 seznamu
pm2 save# Uložit aktuální seznam procesů pro autostart po rebootu
pm2 monit# Živý monitoring CPU/RAM per proces

📋 Log Management

  • Herní server: ~/logs/server_<timestamp>.log + symlink ~/logs/latest.log (rotace >30 dní se maže automaticky ve telnet_restart_7d2d.sh)
  • Restart wrapper log: ~/restart.log (start/stop/restart eventy, lock konflikty)
  • PM2 procesy: logy spravuje pm2-logrotate modul (automatická rotace, žádné ruční čištění potřeba)
  • Game monitor: integrated-game-monitor/integrated_monitor.log
tail -f ~/restart.log# Live log restart wrapperu
tail -f ~/logs/latest.log# Live log aktuálně běžícího herního serveru
pm2 logs# Live logy všech PM2 procesů najednou
pm2 logs takaro-server --lines 100# Logy konkrétního procesu
grep "error" ~/restart.log# Hledání chyb v restart logu
sudo journalctl -u cron | tail -20# Cron systémový log
